# Hotel Booking Cancellation Prediction

IT5022 Fundamentals of Machine Learning – Assignment (SLIIT)

## Problem
Predict whether a hotel booking will be cancelled (`is_canceled`) using information available at booking time.

## Dataset
Hotel Booking Demand – Antonio, de Almeida & Nunes (2019), *Data in Brief*, 22, 41–49.
Kaggle: https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand

## Algorithms
| Member | Algorithm |
|---|---|
| MS26936130 | Random Forest |
| MS26926476 | Logistic Regression |

## Repository structure
